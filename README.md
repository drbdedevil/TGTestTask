# Custom String

Реализация класса динамических строк `String` без использования STL.

Собранный пример программы находится по пути *Bin/*.

### Запуск
Программа-пример принимает строки через аргументы командной строки.

Пример:
```cmd
CustomString.exe check just fix azerbork maks work n
```
Вывод:
```cmd
Result:
work
n
maks
just
fix
check
azerbork
```

Запустить тесты так же можно в *Bin/*:
```cmd
CustomStringTestRunner.exe
```
